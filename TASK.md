# Build a quiz system using Laravel.

## Step 1:

Users can create quizzes containing questions and answers. Each question has exactly one correct answer and at least one incorrect answer. A quiz can have up to 10 questions. A question can have up to 10 answers in total.

## Step 2:

Users can view (take) a quiz, choose their answers, and after answering all questions see their score. Each correct answer grants 1 point.

# Learning Goals
1. Practice designing database tables and relationships using migrations in Laravel and using Eloquent to read and write data
2. Practice building a dynamic UI using modern tools
3. Practice writing code without a lot of AI agent usage
